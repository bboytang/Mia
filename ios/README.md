# Mia iOS

## 情绪伙伴升级（2026-10-13；开发验证中）

首页改为原创玻璃流体小球、八种动态表情与深色背景，取消启动视频、人物和字幕。首次进入待呼叫，不自动录音或发现设备；点小球开始/结束。系统声音快捷指令可调用后台录音动作，另有打开 App 的回退动作；待呼叫期间只有系统口令监听可能使用麦克风。

新增 Live Activity/灵动岛扩展，IPA 重签必须同时保留并签名 `PlugIns/MiaActivity.appex`。锁屏停止使用公开保护数据事件，不能保证精确锁屏时机；后台启动、系统音频交接、发热耗电和扩展重签须真机验收。

设置提供声音唤醒指引和记忆/成长管理。管理请求只在现有设备认证后的 WebSocket 内发送，无需启动麦克风。实际小智服务尚未部署扩展时会明确超时提示；不能把本地模块视为已上线长期记忆。

## 当前接入：自建小智 0.9.7

按用户要求暂不使用账号 UI，设置改为可配置 OTA / WebSocket 和设备绑定。Mia 先请求 OTA 获取本机设备令牌，未激活时显示验证码，用户在智控台将设备关联智能体；激活后才建立 hello/session_id 和打开麦克风。不会把旧账号令牌发给小智。WS 配置是实际目标，OTA 用于核对主机和安全级别；HTTPS/WSS 正常验证证书，当前 IP 的明文例外只用于用户选定的自建服务器。

[协议、文件改动、激活步骤与测试记录](../docs/mia-xiaozhi-integration.md)。旧账号说明是历史回滚参考，当前界面不提供注册/登录；代码和钥匙串数据保留。当前 GitHub 编译和新增 XCTest 尚待核对，真实服务器已通过绑定及 hello，但测试录音上传后尚无 STT/TTS，真机端到端未通过。

`ios/project.yml` 是 XcodeGen 工程定义。GitHub Actions 的 `Build iOS App` 工作流在 macOS runner 上生成 Xcode 工程，并分别编译模拟器和未签名的真机应用。

工作流上传 `Mia-unsigned.ipa`、`Mia.app` 和 SHA-256 校验文件。IPA **没有 Apple 签名，不能直接安装**；使用你自己的签名方式重签后才能安装到 iPhone。无需在仓库中保存签名证书或服务器密钥。

当前已加入小智 WebSocket 版本 1、Opus 编解码、麦克风采集与播放管线，以及仅展示 Mia 回答的字幕时间线。首页已按用户批准改用原半身 Mia 与星雾背景、无图标流光球；正式 Live2D 仍需分层绑定模型。默认服务端地址为 `wss://8kraw.cloud/xiaozhi/v1/`。已按[用户名＋密码方案](../docs/mia-account-access-plan.md)接入注册、登录和退出；新安装轻触流光球即可登录或注册，无需复制网关令牌。服务器已通过真实合成语音回合，但外部 TLS 与 iPhone 联调尚未通过。

账号会话保存在本机钥匙串，绑定服务端来源，有效期 30 天；密码不保存。网络/TLS 错误保留原登录，明确的“未授权”才使会话失效。退出先断开语音并清除本机登录；撤销失败会提示，稍后可重新登录或请管理员重置密码以撤销全部会话。旧版已有令牌的安装只在首次升级迁移为维护模式；登录或退出后不会自动退回共享令牌。管理员仍可在“设置 → 高级维护”手动选择维护令牌并更改服务端。完整进度、系统方案、验收标准和后续实施顺序见[项目路线图](../docs/mia-ios-roadmap.md)。

## 静音启动动画

2026-10-05 用户取消启动音效，选择[新版星雾静音视频](../docs/design/launch/mia-starmist-preview-silent.mp4)推送。已原样放入 `ios/MiaApp/MiaLaunch.mp4`：H.264、768×1376、24 fps、5.167 秒、124 帧、无音轨。此前声音预览仅保留制作历史，不打包到 App。

播放器通过本地静音 MP4 覆盖在同一首页实例上，冷启动播放一次；支持跳过、Reduce Motion、后台停止、失败回退和 7 秒上限，最后 0.25 秒按媒体播放时间淡出。它不发起联网、麦克风权限或音频会话，继续保持 `isMuted=true`。由现有 XcodeGen 资源规则打包；CI 额外核对真机 App 内资源与源文件字节完全一致。

播放测试使用测试包内的 `MiaLaunchFixture.mp4`：16×16、2 秒、48 帧、无音轨的黑色视频，只验证 AVPlayer 生命周期和回退。CI 将上传两台模拟器的实际启动录屏与首页截图。Swift/Xcode 在本地 Linux 环境不可用，[静音版 CI](https://github.com/bboytang/Mia/actions/runs/37250809373)（代码 `13dd7ce`）通过 49 项单元测试、2 项 UI 测试、模拟器与未签名真机编译、资源一致性检查；IPA 已上传。已下载核对 App 视频与源文件一致，并抽查 16 Pro/SE 实际录屏均有粒子、Mia 与回到首页。主录屏 177.15 秒、542 帧，SE 22.83 秒、443 帧，均无音轨；时长包含模拟器启动等待，不代表真机速度。结尾角色/流光球与原生布局有位置及尺度变化，未宣称像素级无缝；真机流畅度和衔接待验。

## 半身星雾首页（2026-10-04）

用户最终恢复原半身形象，并批准星雾背景、取消左上文字、保留设置及字幕、用无图标流光球替换旧麦克风圆钮与柱状波形。`MiaPortrait` 与 `StarMistBackground` 分层展示，前景星雾和渐隐覆盖人物下沿；`MiaFullBody` 和城市资产保留历史。

流光使用原生 `TimelineView`/`Canvas`，上限 24 fps，后台暂停；Reduce Motion 时几何静止但亮度仍能反馈声音。录音输入每 60 ms PCM 帧计算 RMS，Mia 回答继续复用原播放音量；停止录音或断开时归零，旧播放回调不覆盖新聆听反馈。字幕推进和录音/Opus协议保持，点击仍可开始、结束及打断。新增 3 项 PCM 能量测试；构建 `305a45d` 的 [CI](https://github.com/bboytang/Mia/actions/runs/37213166341)通过模拟器与未签名真机编译、全部 35 项 XCTest，已核对 [16 Pro/SE 首页缩略截图](../docs/design/README.md)。真实语音流光反馈与真机音量灵敏度待验。

新半身末帧与从下沿向上凝形的提示词已同步；用户已取消音效并选择静音版接入，视频没有音轨，播放器仍静音。此次没有创建新收费任务；两尺寸录屏已确认播放并回到首页，实际布局不是像素级无缝；真机流畅度仍待验。
