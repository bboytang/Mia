## 目标与产品行为

Youmi 是有主见的伙伴，自动记住重要内容，性格尽量从长期相处中形成。
不训练新模型；使用持久记忆、性格档案和当前情绪。情感指一致的表达与回应，不声称模型有人的主观感受。

| 场景 | 行为 |
| --- | --- |
| 打开 App | 直接显示小球，待呼叫；不播放启动视频，不自动录音或上传环境音 |
| 点小球 / 说“你好，米娅” | 开始对话；口令由系统声音快捷指令识别 |
| 聆听 / 思考 / 回答 | 眼神、动作与流体对应当前状态；情绪跟实际音频播放变化 |
| 切后台 | 已开始的聊天继续；灵动岛显示迷你 Youmi 和状态 |
| 结束对话 | Youmi 释放麦克风；系统声音快捷指令仍可以监听下一次呼叫 |
| 锁屏 | 目标是停止 Youmi 录音和回答，允许系统继续监听口令；需真机验证公开 API 的停止时机 |
| 解锁 | 可再次说口令；不保证解锁本身自动恢复 App 执行 |

后台启动不获系统许可时，回退为“打开 Youmi 开始聊天”；不将回退标为后台直接聊天通过。
系统麦克风与 App 麦克风须区分，不能声称手机完全停止监听。

## 界面与情绪

- 删除人物立绘、星雾、底部流光按钮和字幕展示，取消启动播放器/视频打包及相关 CI 检查。
- 首页球体直径约屏宽 60%，位于中心偏上。蓝紫流体、橙粉亮色、透明玻璃外壳；深蓝黑背景、柔和光晕和少量慢光线。
- SwiftUI + Metal 绘制材质，眼睛和动作独立；前台目标 30 fps，后台停绘；尊重减少动态效果。
- 视频只是参考，不裁剪含署名的素材作为产品资产。保留设置、错误、权限和设备绑定提示。
- 八种情绪：平静、开心、好奇、惊讶、疑惑、关心、失落、俏皮。情绪强度有界，连续过渡。
- 聆听/思考/说话是动作状态；语境决定情绪，音量只决定起伏和亮度。
- 回答文字和情绪由同一模型产生；依实际播放同步，打断/结束/重连后旧回调不能恢复旧表情。
- TTS 优先复用当前服务；仅使用已验证的情绪参数。不新增好感分、惩罚、依赖或因用户离开而埋怨。
- 点小球开始/结束；保留开口打断。明确停止指令为“米娅，结束聊天”“米娅，休息吧”，不能把引用和讨论当退出。

## 系统入口与灵动岛

- 提供开始/结束聊天 App Intents，系统设置中训练“你好，米娅”；App 提供指引，不能自动修改辅助功能设置。
- 优先使用 AudioRecordingIntent + Live Activity；提供打开 App 的显式回退动作。
- 灵动岛紧凑形态：小球和状态；展开：表情、短状态、结束及首页入口。
- 待呼叫显示“待呼叫”，不冒充 App 正在监听。只按状态/情绪更新，不传逐帧音量或音频。
- Live Activity 只用静态表情和短过渡，不承诺完整持续流体动画、永久占据或无限显示。
- 锁屏只用公开接口；保护数据事件不是精确屏幕开关通知。必须实测；不采用私有 API、静音保活或绕过系统。
- 开发者模式仅用于安装/调试，不能解除后台限制。App 被划掉后的恢复依靠用户系统动作。

## 记忆与性格

| 信息 | 内容 | 规则 |
| --- | --- | --- |
| 用户记忆 | 偏好、目标、身份事实、重要关系 | 依据用户陈述，可纠正 |
| 共同经历 | 重要事件、约定、交流结果 | 带时间和真实来源 |
| 性格档案 | 表达、幽默、互动和兴趣倾向 | 至少三个不同会话支持后慢更新 |
| 当前情绪 | 本轮回应的情绪/强度 | 短期状态，不当作永久性格 |

流程：识别文本 -> 最近对话/性格/相关记忆 -> 回答和情绪 -> 语音/表情 -> 异步提炼记忆。
默认最多 20 轮短期上下文、8 条相关记忆；每 10 轮或会话结束提炼；首句不能等待额外提炼。
不长期保存原始录音或完整聊天，只保留必要来源片段；敏感候选先确认，密码/验证码/令牌不保存。
玩笑/假设/引用/模型猜测不能变事实；临时情绪不能变永久标签。明确纠正优先，冲突不确定时询问。
“记住这个”提高优先级，“这段别记”暂停提炼，“忘掉这件事”删除记忆及衍生摘要。
设置提供查看/修改/确认/删除/暂停/全部清空，以及性格依据和重置。
性格只固定诚实、尊重、有判断、不编造共同经历；每次整理最多改一个特点，保存版本和证据。
删除支撑记忆须失效相关性格；不编造人生、身体体验、关系事实。

## 架构与接口

- 当前 App 使用实际自建 xiaozhi-esp32-server 0.9.7；不启用旧 `server.youmi_gateway`。部署前核对实际源码，接Youmi扩展点。
- 新记忆模块 SQLite + FTS，不新增独立向量数据库/第三方记忆云；复用已配置模型与认证。
- 服务端认证、绑定后的身份确定 owner；禁止信任请求中的 owner/昵称。不同绑定不能串记忆。
- 记录包含 ID、类别、内容、来源、时间、确认状态；来源去重、性格证据和删除 revision 防止在途提炼重建已删数据。
- WebSocket `mia_memory` 请求有 request_id/action；认证后查看、修改、删除、暂停、清空、性格/重置。响应是有界 JSON。
- `tts.sentence_start` 可选 emotion/intensity，旧客户端忽略；无标签/非法标签退为平静，不破坏对话。
- 记忆作为数据，不作为系统指令或工具授权。提炼/DB 失败不能损坏已有记忆或阻止普通聊天。
- 按绑定身份隔离；重装身份改变需显式迁移，不根据昵称合并。
- 自建存储不等于离线：云端模型仍会接收请求中检索出的记忆。

## 验证、部署与范围

先验证声音快捷指令、后台录音交接、锁屏、Live Activity 和扩展重签；回退行为有独立结果。
视觉先验收平静/开心/疑惑/关心四种预览，再补齐八种。先验证记住/纠正/忘掉，再启用成长。
测试覆盖权限、后台/锁屏/解锁、电话/蓝牙、打断/重连、迟到回调、跨会话/重启持久化、隔离、删除竞态、敏感信息、无效模型数据。
CI 包含原生 XCTest/UI、模拟器/设备与扩展打包、服务端回归；至少一次 30 分钟真机交替前后台记录发热/耗电/唤醒。
更新前备份配置和数据库；回滚代码不删记忆。沿用 Bundle ID、设备身份与凭据，交付单独 IPA。
不新增账号、声纹、独立向量库、自训练模型、自建常驻唤醒引擎；未验证的后台/锁屏能力不可标为完成。
