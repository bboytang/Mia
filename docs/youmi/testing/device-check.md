| 情绪 | 开心、疑惑、关心、平静可区分；表情和实际说出的回答一致 | 待测 |
| Reduce Motion | 减少运动但可看到状态/表情，仍能开始/结束 | 待测 |
| VoiceOver | 小球开始/结束、设置、记忆确认/删除均可操作 | 待测 |

连续30分钟交替前台/后台：记录初末电量、温度/发热、网络类型、口令总次数/成功次数、异常中断次数。
原始录音、真实密码/令牌和敏感聊天不放进仓库；诊断只记录状态/计数和必要脱敏描述。
实际服务端未部署时，记忆页面应明确显示不可用；不能据此判定持久化已经通过。
