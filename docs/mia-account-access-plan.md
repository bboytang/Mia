# Mia 用户名与密码登录设计

日期：2026-10-04；2026-10-05 更新。状态：**账号功能已实现、CI 通过并部署 VPS，本机账号链路验收通过；公网 TLS 与 iPhone 验收待备案恢复后完成**。

用户已决定使用用户名＋密码注册登录，取代普通用户手填网关令牌。已确认的半身星雾首页和无图标流光球独立实施；本方案不改变小智协议、Opus、火山 Provider、字幕推进或录音按键方式。

## 使用流程

1. 新用户安装并打开 Mia，点击流光球进入登录页，可切换到注册。
2. 输入用户名与密码，注册成功即登录；服务器自动签发会话，App 保存到钥匙串，用户不接触令牌。
3. 下次打开恢复未过期会话，可直接开始语音。会话有效期为 30 天，不保存密码，不另加 refresh token。
4. 设置页显示当前用户名与“退出登录”。退出时先取出当前会话供撤销请求使用，立即停止本机语音并清除本机会话；若离线或服务器撤销失败，明确提示本机已退出、服务端撤销未确认。
5. 明确到期或未授权时重新登录；普通断网、TLS 错误不清除有效登录信息。
6. 首版没有邮件、短信及自助找回密码。忘记密码由管理员通过受保护的本机命令重置，并撤销该账号既有会话。

用户名支持汉字、字母、数字和下划线，长度 3–32 字符；NFKC 与 casefold 后唯一。密码 15–128 字符，支持空格与粘贴，不强制大小写/数字组合，不 trim、不截断。[长度依据](https://pages.nist.gov/800-63-4/sp800-63b.html)。

## 技术选择与范围

采用自管 SQLite 用户库与随机会话，不引入 JWT、第三方账号服务或独立后台管理站点。相对于第三方账号服务，这符合现有 VPS 和无邮件/短信的用户名注册方式；随机会话可直接撤销，不需另外维护签名与刷新流程。

- 新增 `server/account_store.py`：用户、密码散列、会话、每日语音用量。
- 新增 `server/account_http.py`：注册、登录、退出及 HTTP 错误转换。
- 一个进程、同一 asyncio loop：现有 WebSocket 继续监听 `127.0.0.1:8765`，HTTP 账号接口监听 `127.0.0.1:8766`，Caddy 统一提供 HTTPS/WSS。
- 仅增加 `aiohttp` 直接依赖，版本固定后安装于项目虚拟环境。采用官方 `AppRunner`/`TCPSite`，不手写 HTTP 解析。[启动接口](https://docs.aiohttp.org/en/stable/web_reference.html#running-applications)。
- `xiaozhi_gateway.py` 只调用账号鉴权/用量能力；密码与 HTTP 细节不塞入 Gateway 或 Provider。

现有 websockets 16.0 的 HTTP Request 不暴露 POST body，不能直接用其握手回调充当 JSON 注册接口。

## HTTP 契约

| 接口 | 请求 | 成功 |
| --- | --- | --- |
| `POST /api/auth/register` | JSON：`username`、`password` | 201；注册并返回会话 |
| `POST /api/auth/login` | 同上 | 200；返回会话 |
| `POST /api/auth/logout` | `Authorization: Bearer` | 204；幂等撤销当前会话 |

会话响应只包含 `username`、`token`、`expires_at`，设置 `Cache-Control: no-store`。会话是仅供 App 自动使用的凭据，不展示在产品界面。

输入错误返回稳定 400/415；重复用户名 409；未知用户名或错误密码统一 401；超大请求 413；限流或过载 429 并附 `Retry-After`。内部错误仅返回通用提示，不回显输入、SQL 或堆栈。正文最多 4 KiB；不记录密码、请求正文、Authorization 或完整会话。

## 数据与会话

- 用户表保存规范化用户名、随机 salt、密码散列与创建时间。
- 会话表保存随机令牌的 SHA-256、用户 ID 和到期时间；数据库不存明文密码或原始令牌。
- 注册/登录时清理过期会话；每账号保留最多 5 个有效登录会话，超出后撤销最旧会话，避免重复登录无限积累记录。
- 用量表按用户与 UTC 日期原子计数；重启不会清零。
- 密码使用 `hashlib.scrypt`：`N=2^15, r=8, p=3`、16 字节随机 salt、32 字节输出、显式 64 MiB maxmem。[参数依据](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。
- 散列在后台线程执行，并发上限 2；不存在用户也执行同成本验证，避免阻塞音频事件循环或通过时序明显区分用户。
- SQLite 使用参数绑定；受限请求与工作线程并发不得绕过注册数量、重复用户名及用量约束。

## 初期用量边界

普通用户开放自行注册，初始最多 **100 个账号**；每账号每日最多 **30 轮非空语音回合**，全站同时最多 **2 轮**，包括旧共享令牌的维护连接；旧令牌只免除每账号日额度。这些数值可通过受保护的服务器配置调整。空录音和在限额检查之前被拒绝的请求不扣轮数，也不调用云 API；已启动但失败/被打断的回合仍计入用量，因为可能已调用云服务。

先取得全局并发名额，再原子扣账号轮数；未取得名额不扣额度，完成、异常和打断均释放名额。密码散列并发上限约束实际运行线程；请求取消后，已有线程仍占名额直到计算完成。

注册/登录还按真实客户端 IP 与用户名限制尝试频率，限制在昂贵的密码散列之前执行；不永久锁定账号。Caddy 覆盖客户端 IP header，HTTP 服务只信任来自 loopback 代理的该 header。达到限额给出中文提示，不进入火山 API。

## 保留原语音协议与回滚

登录后仍使用现有 `Authorization: Bearer` 连接 `/xiaozhi/v1/`，不增加小智消息类型。旧 `MIA_GATEWAY_TOKEN` 仍保留供维护和回滚；不把这个共享凭据写进 IPA。

会话在 WebSocket 建立时及每次新语音回合调用 Provider 前校验。已过期或已撤销的会话拒绝新回合，错误凭据仍为 WebSocket 1008。本机退出立即断开正在进行的回合；不在首版增加跨设备后台广播。

普通设置页隐藏手填令牌入口；折叠的“高级维护”保留旧方式。已有旧版管理员安装可继续用原令牌，朋友的新安装走账号流程。

登录账号或退出账号之后不自动回退到钥匙串中的旧共享令牌；只有用户明确选择高级维护模式才能再使用旧方式，防止退出后仍有语音权限或绕过账号额度。

## iOS 边界

- 新增账号 API 与登录/注册 sheet；普通用户不填写服务地址或长令牌。
- 钥匙串保存同一可信服务 origin、用户名、会话和到期时间。密码只在当前输入/请求期间存在。
- 原 WSS 地址转换为同 host/port 的 HTTPS 账号地址；禁止 URL 用户信息，不把一个服务器的登录会话发往另一个 origin。
- 成功响应完整验证后才更新钥匙串；失败或取消不写入半完成数据，更新失败不删除原会话。
- VoiceSession 保留录放/字幕生命周期，仅对明确鉴权失效提示登录；流光球继续保留当前开始、结束和打断语义。

## 部署与备份

数据库位于 `/var/lib/mia/accounts.sqlite3`，归 `mia` 用户，目录权限 0700；systemd 加 `StateDirectory=mia`，不把数据放进代码目录。安装器保留已有火山 Key、旧网关令牌和数据库。Caddy `/api/auth/*` 转发 8766，旧语音路由不变。

账号模式可关闭并回到共享令牌方式；保留数据库以便恢复。数据库备份与代码回滚分开，不通过 Git 发布用户数据。管理员重置命令隐藏输入密码，不打印或保存密码。

## 验证与完成标准

1. Store：不同 salt、正确/错误密码、重复及并发注册、会话持久化/到期/撤销、用量并发和重启、数据库无明文凭据。
2. HTTP：注册→登录→退出、统一错误、正文上限、限流在散列前、过载/取消释放资源，不回显 secret。
3. Gateway：账号会话走原 Opus→ASR→LLM→TTS→仅 Mia 字幕；连接后退出不能再启动收费回合；错误令牌、empty、abort、旧令牌和 Provider 回滚全部通过。
4. iOS：请求/响应、同 origin、过期与断网区别、取消、钥匙串成功保存和退出清除；编译、自动化测试及两种尺寸截图。
5. 部署后用临时测试账号检查注册、登录、原 WSS 握手及退出拒绝，不将本机或 VPS 自测写成 iPhone 验收。备案外部 TLS 若仍受阻，真实 iPhone 登录/录音仍明确待验。
