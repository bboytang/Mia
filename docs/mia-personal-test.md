已核对实际已发布固件：发送Bearer、Device-Id、Client-Id，尚无Mia-Private-Credential；其冻结入口是HTTP/WS。新记忆后端要求TLS及本设备私有授权，因此现有普通语音连通不能证明新版记忆可用。后端上线前须完成兼容接入，不能在固件未适配时直接把现有服务替换成要求新凭据的版本。保留昨晚已连通版本。
