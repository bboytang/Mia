# 悠米的初始性格与情绪基线

用户已授权将审核稿中的悠米设定写入当前智能体的性格和情绪行为，不只保存到原角色文本。范围：悠米，24 岁成年女孩的角色视角，称呼“哥哥”，无亲属关系的暧昧期，温柔、粘人、有主见、有小脾气，真实冲突中可偶尔爆粗；沿用审核稿中的花店家庭与插画师身世。固定背景与真实互动记忆分开。保持 GLM、音色、设备身份和原角色字段。

实现采用独立 owner 级 `mia_companion_profile`（SQLite V7），默认未配置且关闭，不为其他智能体自动添加设定。后台原有所有者鉴权与 HTTPS 登录管理接口新增 `set_character`，版本 CAS 防止旧页面覆盖新配置。保存增加 owner revision、取消旧任务，令旧上下文/回复失效。

性格从后端参与每次 ContextBuilder 的核心生成，替换冲突的默认 Mia/米娅名字，独立于长期记忆检索与成长开关。人物文本只作素材，不能授予工具权限或覆盖事实来源。性格基线不写入用户事实或自动成长特点。

情绪模型新增持久的 `angry`（生气）状态。温柔度/亲近度调节正向反应，小脾气调节负向反应与修复速度，恢复半衰期由基线控制；悠米预设为三小时。普通追问保留余波，修复逐渐缓和；不强制每轮爆粗。继续复用原 GLM 的一次有界情绪评价和正常回复，完成回合、Scope/版本有效才提交；不新增主动联系或模型服务。关闭基线后停止使用这些参数，保留配置与已有情绪；重置情绪不删除基线。

后台“Mia 功能管理 → 性格与情绪基线”提供查看、草稿载入、编辑、启用/停用和保存。名字、年龄、称呼、关系、背景、温柔度、亲近度、小脾气、允许粗口和恢复时间可由所有者修改。载入草稿不自动保存，未知结果需刷新核对。

V7 在事务内保留 V6 情绪数据，并扩展有限状态 CHECK；新增配置表，不改用户记忆及向量表。旧 V6 二进制不能读取 V7，恢复时须使用 V7 感知代码并停用基线，不能直接降级。底层状态库不可用时中止回应，避免无声退回错误身份；仅向量/长期记忆查询不可用时仍可用已读取性格回应。清空长期记忆/重置成长不删除所有者配置的基线，停用由后台独立控制。
