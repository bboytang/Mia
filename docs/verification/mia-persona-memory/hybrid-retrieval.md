## 固定算法与证据

沿用P06已冻结初选：S／L／A／E权重0.58／0.28／0.08／0.06、综合阈值0.20、原查询余弦底线0.35、Top4。未重新调参，留出集不能用于调参。S直接夹取真实余弦到[0,1]，不采用会让无关候选难以拒绝的距离倒数。

`SemanticMemoryIndex.retrieve`在既有SQLite上运行，复用固定编码器、授权及快照。先按可信owner／mia Persona／confirmed／active筛选全部候选和扩展线索；同Scope有效触发词命中后，从对应实体和关键词取最多8个去重线索。扩展记录事实ID、内容／证据版本及实际触发词；只编码数据，不产生新事实或系统指令。原查询保留；原查询及扩展文本均不超过4096字符，没有剩余空间就不添加相应线索。

按256条有界块同时计算原查询与扩展查询余弦，分别保留前12；再以相同Scope内L和A各前12补充，合并候选最多48。受控测试固定13个语义更强的干扰事实，检验语义前12以外的目标是否经扩展／补充保留；真实中文报告另外记录实际扩展与遗漏情况，不将受控向量称为真实语义。

每个候选记录原／扩展余弦、候选来源、S／L／A／E、总分和是否过门槛。L沿用P06中文二元词组Jaccard×2.2及实体／关键词／触发词命中贡献；A按实际触发词命中每项0.35、最多1；E是事实的情绪重要性，不是用户长期情绪。缺失情绪仅在计算时贡献0，数据库保留NULL；普通低情绪事实仍可入选。S取原／扩展余弦较大值，但所有入选者必须独立满足原查询底线，高情绪或扩展相似度不能绕过它。有效无关问题返回空结果，缺索引／坏元数据／推理故障明确不可用，无FTS或最近事实回退。
