# Mia iOS 开发路线与验收门槛

## 已实现的基础

- 独立 iOS 17+ SwiftUI 工程；GitHub macOS runner 执行模拟器测试、真机构建并上传未签名 IPA。
- 中文未来都市首页、应用图标、服务端设置和本机钥匙串令牌。
- 小智 WebSocket 版本 1 握手与 `listen` 控制；16 kHz 上行和服务器协商采样率的 Opus 编解码；麦克风采集和音频播放管线。
- 仅消费 Mia 的 TTS 文本作为字幕，按实际音频播放回调近似逐字显示。用户 STT 不进入字幕。现阶段没有服务端字符级时间戳，不能保证每个字与发音严格对齐。
- 仅供联调的固定答复服务，使用真实 Opus 测试音。它不是 AI 服务。
- 可配置的云语音网关代码，使用云端中文 ASR、LLM 和 TTS；自动化测试通过假提供者验证，不代表已在真实 API 上验收。

## 推荐的正式服务

首个可用版本建议在美国 Ubuntu VPS 上运行小智兼容网关，由云端 API 完成推理。优先采用同一提供商的中文 ASR、轻量 LLM 和流式 TTS，减少账号和接口组合成本。可先评估 OpenAI 的 `gpt-4o-mini-transcribe`、`gpt-4o-mini`、`gpt-4o-mini-tts`；正式接入前核对账户所在地区、实时价格、中文音色和服务条款。若音色或字幕时序达不到要求，TTS 可换成支持中文语音及词边界事件的服务，网关协议保持不变。

VPS 只负责 WSS、鉴权、Opus 转换与 API 编排，不在 2 核 2 GB 主机上运行大模型。API 密钥只放在 VPS 环境变量或受限权限的配置文件中。客户端只保存网关令牌，绝不内置云服务密钥。

## 接下来的实施顺序

1. **真机与联调夹具**：在 iPhone 上重签安装 GitHub 的未签名 IPA；将测试服务仅在 VPS 本机监听，通过 Caddy 与域名暴露 WSS。验证握手、麦克风权限、Opus 播放、字幕、中断、弱网与耳机切换。需要 VPS 的域名和 SSH 连接信息，不需要把密码提交到仓库。
2. **真实语音网关联调**：用户开通所选云 API 后，部署仓库中的 ASR → LLM → TTS 网关。首轮采用按键开始/结束说话。验证中文问答、延迟、费用、超时、取消和错误提示。此阶段可能根据服务端兼容性调整 `Device-Id` 接受规则。
3. **字幕和 UI 收尾**：服务端输出 TTS 片段对应的文本边界或时间戳；客户端用音频播放时钟校准字/词显示，处理多句排队和打断。完成台词回看、音量控制、辅助功能和各尺寸 iPhone 布局。
4. **正式 Live2D**：收到合法授权的 Cubism 模型文件后接入 Cubism SDK，音频能量驱动 `ParamMouthOpenY`，可用表情与状态驱动动作。验证 60 fps、内存、发热、前后台恢复。角色概念图与静态首页背景不算 Live2D 模型。
5. **发布与维护**：每次提交由 GitHub Actions 编译。用户自行签名 IPA 并真机验收。无 Apple Developer Program 付费账号时不把 TestFlight/App Store 作为交付承诺。

## Live2D 美术交付清单

角色参考是已选定的紫色短发、黑紫赛博服饰 Mia。正式交付需有角色使用授权、分层源稿、Cubism 工程源文件、可运行的 `.moc3`、`.model3.json`、贴图图集、表情/动作文件。绑定至少覆盖眨眼、视线、头部转动、呼吸、身体轻摆、情绪切换和 `ParamMouthOpenY`；嘴部建议额外提供形状参数以支持音素或表情扩展。素材需适配竖屏半身构图，主体不得遮住底部字幕和麦克风。

当前没有可运行的原创 Cubism 模型，也没有可执行绑定工作的 Windows/Cubism 环境或画师，因此正式 Live2D 接入暂不具备输入条件。可以先用合法的测试模型验证 SDK 渲染，但最终验收必须换成有权使用的 Mia 模型。

## 尚需外部输入

- VPS 域名及 SSH 可连接地址，供测试服务和 WSS 部署；不要在聊天或仓库中发送密码、私钥。
- 选定云 API 后由用户自行开通的账号和额度；密钥通过服务器安全渠道配置。
- 完成绑定且获授权的 Live2D Mia 模型；仅靠单张概念图无法生成 Cubism 模型。
- 用户自行签名后的 iPhone 真机反馈，以验证麦克风、扬声器、延迟和布局。
