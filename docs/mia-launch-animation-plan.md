# Mia 启动动画：已确认方案与制作计划

更新：2026-10-04。分支：`feature/mia-ios-bootstrap`。用户已确认按「星尘凝聚 → Mia 旋身亮相 → 指尖点亮首页」制作成品。

## 已确认分镜

约 5 秒、竖屏、一镜连续演绎。沿用[已选右侧第三款 Mia](design/README.md)，不更换角色、服装或首页。

| 时间 | 画面与动作 |
| --- | --- |
| 0–1.2 秒 | 深色空间中，细密蓝紫渐变粒子形成柔软的立体云团，内部少量粉色暖光；轻微呼吸和旋转。 |
| 1.2–2.2 秒 | 同方向旋转逐渐加速，轨迹收紧，粒子云拉出头、肩和身体轮廓。 |
| 2.2–3.3 秒 | 晶体发饰先成形，紫色短发、脸、服装和手臂沿流动方向显现；轮廓边缘仍有粒子。 |
| 3.3–4.5 秒 | Mia 从轻微侧身转向镜头，头发和外套有惯性；近脸的手划出晶体光弧，收为原有 V 手势，另一手保持向镜头伸出。 |
| 4.5–约 5.2 秒 | 光弧流向麦克风环，城市、字幕板和控件显现；角色姿态、尺度、位置与首页衔接，减速收束。 |

不使用硬切或闪白掩盖变形。粒子、转身和光弧保持共同的运动方向与蓝紫色系。5 秒生成素材可在合成时加入短暂首页衔接；不能靠加速拉伸掩盖角色动作问题。

## 最小接入范围

- `ios/MiaApp/MiaApp.swift`：持有一次冷启动的播放状态。
- `ios/MiaApp/MiaLaunchPlayback.swift`、`MiaLaunchView.swift`：本地静音视频、结束和失败处理、跳过、Reduce Motion、后台停止和资源释放。
- `ios/MiaApp/MiaLaunch.mp4`：验收通过后加入的成品；制作中不放入冒充成品的占位视频。
- `ios/MiaTests/MiaLaunchPlaybackTests.swift`：完成、跳过、失败、缺素材、辅助功能、后台与超时行为；使用测试包内的 16×16、2 秒静音 H.264 文件，不能用测试素材冒充成品。
- `.github/workflows/ios.yml`：首页截图等待启动完成，并保留模拟器启动录屏。
- `ios/README.md`、交接和路线图：分别记录使用方式、实际证据与待验项。

首页长期保留同一个 `ContentView` 和语音会话；覆盖播放期间阻止首页交互与无障碍焦点，退出覆盖后恢复。动画不请求麦克风、不启动音频会话、不连接服务器、不保存重播标记到用户设置。缺素材、播放失败或最长 7 秒无法完成时进入原首页。返回前台不重播。

## 素材与工具

- 用户上传的视频只作为粒子质感与运动参考，原视频不公开上传。
- [原创粒子首帧](design/launch/mia-particle-start.png)：用内置 imagegen 生成。提示词核心为深色竖屏、蓝紫超细粒子立体云团、少量粉色内光、连续旋转前的安静状态；无角色、文字或 UI。
- 角色与末姿以现有 `MiaPortrait` 和真实首页布局为依据。静态关键帧不代表转身动画完成。
- OpenArt 已安装，用户已确认连接账号；新会话上下文中的视频工具可调用。实际表单与报价支持 PixVerse V6 的首/末帧图片生成 5 秒视频，不能添加表单未提供的画幅字段。
- 2026-10-04 用户选择先用现有 40 积分生成 360p 动作预览。仅提交一次，40 积分已使用；实际输出为 360×640、约 5.04 秒、24 fps、H.264、无音轨。输入为 933×1686，输出映射为标准 9:16，不能把画幅完全继承输入写成已验证。
- [预览视频](design/launch/mia-launch-preview-source.mp4)、[生成提示词](design/launch/mia-launch-preview-prompt.txt)、[已清理元数据](design/launch/mia-launch-preview-metadata.json)已保存。没有密钥、账户标识或签名下载地址。
- 抽取九个时点检查：粒子成形、转向与光弧出现；中段发饰/服饰与既定 Mia 有偏差，且带 OpenArt 水印。此片仅供动作讨论，**未验收为正式启动素材**，没有加入应用的 `MiaLaunch.mp4`。
- 生成时的单条报价为 360p 40、720p 70、1080p 150 积分；后续须重新查询报价。尚未验证更高画质或无水印导出条件，不能承诺仅提高分辨率会解决水印与造型问题。
